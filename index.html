About the project

Built to be opened, forked, and improved.

BizIQ is an open-source demo by Krishna Prakash Ojha (Leon) at OmegaAPI. It uses Cloudflare Pages and D1, a signed three-day preview lock, and no payment layer. You can clone it and run your own instance for free.

What is included

  • Automatic lead capture from plain text
  • Transparent scoring with self-adjusting weights
  • Bot activity recorder and pipeline review
  • Four business calculators
  • Local Ollama bridge, cloud BYOK adapter
